# MusTaxi 🕌🚕

Мобильное приложение такси для мусульманской аудитории. MVP-каркас на **React Native (Expo) + TypeScript**.

## Ценностное предложение

Такси, которое уважает нормы и образ жизни мусульман:

- **Выбор пола водителя** — пассажирки могут заказать водителя-женщину.
- **Время намаза и Кибла** — расписание молитв по геолокации, направление на Каабу, ближайшая мечеть по маршруту.
- **Настройки поездки по нормам** — «без музыки», «тихая поездка», отметка «соблюдаю пост» (Рамадан), возможность остановки на намаз.
- **Оплата без риба** — прозрачный тариф без ссудного процента; чаевые добровольны и считаются отдельно.
- **Мультиязычность** — русский, арабский (RTL), английский.

## Технологический стек

| Слой | Технология |
|------|-----------|
| Фреймворк | Expo (React Native) |

| Навигация | React Navigation (stack + bottom tabs) |
| Геолокация | expo-location |

## Запуск

```bash
npm install
npm start        # затем 'a' — Android, 'i' — iOS, 'w' — web
npm run typecheck
```

> Карта в MVP — заглушка (`MapPlaceholder`). Для продакшена подключается
> `react-native-maps` (Google Maps на Android, Apple Maps на iOS) с реальными
> маркерами водителей, точками маршрута и слоем мечетей.

## Что уже работает в прототипе

- ✅ **SMS-авторизация (OTP)** — двухшаговый вход, демо-код `0000`, сессия
  сохраняется между запусками (`AsyncStorage`).
- ✅ **Реальная карта** (`react-native-maps`) — геолокация пользователя,
  маркеры подачи/назначения, **live-движение водителя** по маршруту.
- ✅ **Полный цикл заказа** через сервисный слой: поиск водителя → подача →
  поездка → завершение, с ETA в реальном времени.
- ✅ **Компас Киблы** на магнитометре (`expo-sensors`) — роза ветров
  вращается по курсу телефона, золотой указатель ведёт на Каабу.
- ✅ **История поездок** + экран деталей (маршрут, водитель, настройки, тариф).
- ✅ **Halal-настройки** сохраняются в заказ и отражаются в истории.

### Как тестировать

```bash
npm install
npm start        # отсканируйте QR в Expo Go (iOS/Android)
```

1. Введите любой номер телефона → код **`0000`** (подсказан на экране).
2. На главном экране выберите пункт назначения из подсказок → «Заказать».
3. На экране заказа настройте пол водителя / нормы / оплату → подтвердите.
4. Наблюдайте движение водителя на карте до завершения поездки.
5. Вкладка **Намаз** — расписание + живой компас Киблы (нужен реальный
   датчик — работает на телефоне, не в веб-превью).
6. **Профиль → Поездки** — история завершённых поездок.

> Сервисный слой (`src/services/api.ts`) полностью имитирует бэкенд в памяти.
> Для перехода на реальный сервер меняется только реализация этого файла —
> экраны и типы остаются прежними.

## Сборка устанавливаемого APK через EAS Build

[EAS Build](https://docs.expo.dev/build/introduction/) собирает приложение в
облаке Expo — устанавливаемый **Android APK** (бесплатно) или сборку для iOS.
Компьютер для этого не нужен. Профили сборки описаны в `eas.json`.

### Путь A — через GitHub Actions, без своего ПК (рекомендуется)

Workflow `.github/workflows/eas-build.yml` собирает APK прямо на раннере
GitHub (`eas build --local`) и публикует его как артефакт:

1. Создайте бесплатный аккаунт на **https://expo.dev**.
2. Получите токен доступа: expo.dev → **Account settings → Access tokens →
   Create token**. Скопируйте его.
3. В репозитории на GitHub: **Settings → Secrets and variables → Actions →
   New repository secret**, имя `EXPO_TOKEN`, значение — ваш токен.
4. Вкладка **Actions → EAS Build (local APK) → Run workflow**, выберите
   `profile: preview` → **Run**.
5. По завершении сборки (~10–15 мин) на странице запуска внизу, в разделе
   **Artifacts**, появится файл **`mustaxi-preview-apk`**. Скачайте, распакуйте
   и установите APK на Android (разрешите «установку из неизвестных
   источников»).

### Путь B — с компьютера (если он есть)

```bash
npm install
npm run eas:login        # вход в аккаунт Expo
npm run eas:init         # один раз — привязать проект
npm run build:android    # сборка APK в облаке
```

По окончании CLI выдаст ссылку на скачивание APK.

### ⚠️ Карты на Android в собранном APK

В **Expo Go** карта работает сразу. В **отдельной сборке (APK)** для Android
`react-native-maps` требует ключ Google Maps, иначе тайлы карты будут пустыми
(само приложение при этом работает). На **iOS** используется Apple Maps —
ключ не нужен.

Чтобы карта работала в Android APK:
1. Получите ключ в [Google Cloud Console](https://console.cloud.google.com/)
   (включите **Maps SDK for Android**).
2. Добавьте в `app.json` в секцию `android`:
   ```json
   "config": { "googleMaps": { "apiKey": "ВАШ_КЛЮЧ" } }
   ```
3. Пересоберите APK.
